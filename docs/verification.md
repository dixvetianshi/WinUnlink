# 验证说明

以下记录对应 v0.1.1，区分实际运行结果与尚未验证的兼容目标。

## 实际环境与命令

验证环境：Windows 10 19044、NTFS、.NET Framework 4.8。

`build.ps1` 构建成功；默认 AnyCPU 在本环境实际运行 64 位进程，另有 x86 构建。`test.ps1` 和 `test.ps1 -Platform x86` 各通过 19 个文件/进程集成场景和 4 个 CLI 场景，注册表测试默认跳过。

全部文件夹具位于项目 `artifacts/tests/**/cases/<GUID>`，占用者为测试自己启动的子进程。成功运行的夹具已清理，测试进程已退出；没有为这些验证删除用户文件或结束用户程序。

## 覆盖的行为

- 普通删除、替换、来源保留、中文与空格路径、只读文件。
- 允许共享删除时占用子进程仍存活，旧句柄继续读取旧内容，删除名称可复用或替换路径可读取新内容。
- 独占占用时返回错误 32 且原文件保留；Restart Manager 报告真实占用 PID 和创建时间，结束对应测试进程后文件操作成功。
- “停止并删除”一次完成独占 ZIP 夹具的停止与删除；零占用删除、目标身份变化前拒绝停止、多个进程的混合停止结果。
- 进程创建时间不匹配、自身终止、目录、备用数据流、同文件及硬链接替换拒绝。
- CLI JSON 报告、中文 UTF-8 输出、无效报告路径与已有报告文件保护。

创建时间拒绝测试没有实际制造操作系统 PID 复用。身份检查回归验证了拒绝过期记录的逻辑，但不能代替全部生命周期场景。

## 菜单与底层探针

旧版普通菜单配置曾执行 10 个检查，包括备份、重复注册、更新程序路径、卸载、同名配置冲突与用户修改保护。这个结果不能视为当前临时模式的完整测试。

当前临时菜单在 Win10 上实际注册并撤回，核对了菜单命令、临时标记、备份和卸载后的菜单项缺失。没有为验证临时生命周期注销或重启系统，也没有完成 Win11 Explorer 菜单视觉验证。

独立 Win32 探针的 AnyCPU 与 x86 运行均返回 `RESULT failures=0`，覆盖 434 字符中文长路径、只读文件、旧数据映射及执行中的自有 EXE。数据映射保留旧内容；执行映像替换被错误 5 拒绝，这是观察到的系统限制，不代表该能力获得支持。探针不等于全部生产分支验证。

## 运行测试与环境边界

默认测试只使用项目内的文件与自建进程，不注册菜单、安装驱动或服务，也不登记重启任务。`test.ps1 -CompileOnly` 只编译，不执行测试程序。

注册表检查必须在隔离的 Windows 沙盒或虚拟机中人工启用 `-AllowRegistryTests`。其测试程序还要求显式 `--allow-real-user-registry` 参数；只清理本次创建且仍为空的父分支，已有或无法确认的配置保持保留。

## 未验证范围

Windows 11、其他 Windows 10 构建、网络共享与其他文件系统尚未进行真实运行验证。重启删除和替换完成实现，但没有登记真实任务或执行重启测试。当前不能宣称在这些环境均已验证，也不能保证完整枚举受保护进程或驱动占用。

权限失败、资源限制、后续确认失败和最终清理失败的所有分支未进行真实故障注入。没有完成全部界面鼠标流程或所有映射类型的兼容性验证。
