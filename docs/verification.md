# 验证说明

本文区分实际执行的检查与实现或测试源码已具备、但尚未验证的路径。

## 环境与测试入口

验证环境为 Windows 10 19044、NTFS、.NET Framework 4.8。默认 AnyCPU 在此环境运行 64 位进程，测试入口也支持 x86。

`test.ps1` 包含文件、文件夹和 CLI 检查；夹具位于项目 `artifacts/tests/**/cases/<GUID>`，占用者为测试自己启动的子进程。默认跳过注册表测试，不安装菜单、驱动或服务，也不登记重启任务。`test.ps1 -CompileOnly` 只构建测试程序。

v0.2.0 的 `test.ps1` 与 `test.ps1 -Platform x86` 均已执行：AnyCPU（实际 x64）和 x86 各通过 22 个文件/进程场景、16 个文件夹场景和 5 个 CLI 场景，注册表测试全部跳过。双入口菜单及升级检查已通过 `-CompileOnly` 构建，没有进行注册表运行检查。

已有文件与目录删除测试显式选择永久删除，避免修改实际回收站。4 个回收站输入与方式校验场景已包含在上述 22 和 16 项中，覆盖过期文件身份、缺少目标、无效删除模式及过期目录快照；它们在调用 Shell 删除前被拒绝，不是额外的真实回收测试。COM 回收执行路径只完成编译，不能用永久删除或输入校验结果证明实际回收成功。

## 文件与文件夹覆盖

文件场景保留普通删除、替换、来源保持、中文路径、只读文件、共享删除旧句柄及独占占用后的恢复。另有“停止并删除”、目标身份变更、PID 创建时间不匹配、系统自身保护和硬链接同身份拒绝等回归。

文件夹场景覆盖递归盘点与删除、空目录、只读子项、整体替换与旧多余项移除、空来源替换、根与子项身份变化、同目录或相互包含的来源、错误类型来源、独占子文件的未完成结果、递归占用汇总及停止后删除、junction 范围拒绝。两个平台还实际通过了父路径 junction 别名的重叠拒绝、中文长目录替换与递归删除，以及过期目录快照的回收预检拒绝。

CLI 检查包含文件与文件夹的只读 JSON 查询，文件与目录数量、中文 UTF-8 输出及无效或已有报告路径保护。

独占目录替换检查实际覆盖了原目录首次重命名被占用拒绝的路径。后续提交失败会尝试恢复原目录，但提交后恢复失败、恢复检查失败及最终备份清理失败没有真实故障注入。递归删除的未完成结果可能包含已经删除的项目；测试只验证已触发的具体失败路径，不能推断覆盖所有并发变化。

## 菜单与底层探针

v0.1.1 的 AnyCPU（实际 x64）和 x86 各通过 19 个文件/进程场景与 4 个 CLI 场景。更早的普通单入口菜单曾执行 10 个检查，不能作为 v0.2.0 双入口、升级和恢复分支的验证结果。

旧版临时文件菜单在 Win10 上实际注册并撤回，核对菜单命令、临时标记、备份及卸载结果；没有注销或重启以验证其生命周期。当前版本不会为测试自动注册文件夹菜单，升级后的用户需在新版手动注册。

独立 Win32 探针的 AnyCPU 与 x86 均返回 `RESULT failures=0`，覆盖 434 字符中文长路径、只读文件、旧数据映射及执行中的自有 EXE。数据映射保留旧内容；执行映像替换被错误 5 拒绝，这是观察到的限制，不代表该能力获得支持。该结果不能代替当前目录实现和全部生产分支的测试。

## 隔离与未验证范围

注册表检查只能在隔离的 Windows 沙盒或虚拟机中人工启用 `-AllowRegistryTests`；测试程序还要求显式 `--allow-real-user-registry`。其清理只处理本次创建且仍为空的父分支，已有或无法确认的配置保留。没有为当前发布测试删除用户数据、结束用户程序或更改系统集成。

Windows 11、其他 Windows 10 构建、真实回收站处理、网络共享与其他文件系统尚未进行真实运行验证。回收成功、用户取消、大文件与 UNC 路径的 Shell 行为均未实测。单文件重启任务没有实际登记或执行，文件夹明确不支持重启排队。没有完成全部界面鼠标流程、Win11 Explorer 菜单视觉检查、全部映射类型及所有权限或资源失败分支的验证。

创建时间拒绝测试没有实际制造操作系统 PID 复用。目录树状态检查没有验证全部并发修改或系统崩溃窗口；整体替换不能宣称为原子目录交换。
