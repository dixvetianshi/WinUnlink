# WinUnlink v0.1.1

首个发布版本：中文 Windows 文件占用查询、删除与替换工具，附便携程序和源码。

- 查询占用进程名称、PID 与程序路径。
- “停止并删除”：确认占用者后结束可处理的程序并自动删除，无需再点击删除。
- 同目录临时文件提交替换，保留来源文件；共享删除允许时保留旧句柄内容。
- 可选普通或临时文件右键菜单，并提供立即撤回入口。
- 管理员可显式登记重启后删除或替换。

## 下载运行

下载便携 ZIP 并完整解压，双击 `WinUnlink.exe`。需要 Windows 10 / 11 和 .NET Framework 4.8 或 4.8.1；请保留同目录的 `WinUnlink.exe.config`。包内 `SHA256SUMS.txt` 可用于校验文件摘要。解压和普通启动不会安装菜单、驱动或服务。

需要移除已启用的右键菜单时，点击窗口里的“移除右键菜单”，或双击包内 `remove-context-menu.cmd`。

## 验证与限制

Win10 19044、NTFS、.NET Framework 4.8 的 AnyCPU（实际 x64）与 x86 各通过 19 个文件/进程场景及 4 个 CLI 场景；当前菜单的完整测试、Win11 实机、网络文件系统及重启执行尚未验证。

删除不进入回收站。停止程序可能丢失未保存的工作。独占句柄和映射限制仍可能阻止操作，本工具不保证所有文件都能在保留占用程序运行的情况下删除或替换。
